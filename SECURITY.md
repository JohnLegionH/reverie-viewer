# Security

## Reporting a security problem

Please do **not** open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting: on the repository page, open the **Security** tab
and choose **Report a vulnerability**. Include what you found, the viewer version, and the steps to reproduce it.

## What to expect

- Reverie Viewer is maintained on a best-effort basis. We will read every report and reply as soon as we can, but we
  cannot promise a response time.
- There is no bug bounty.
- Once a fix is released, we are happy to credit you in the release notes if you would like that.

## Supported versions

Only the newest release receives security fixes.
