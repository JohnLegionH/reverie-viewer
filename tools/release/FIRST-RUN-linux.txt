{NAME} {VERSION} (early preview) for Linux ({ARCH})
=====================================

REQUIREMENTS
- 64-bit Linux on {ARCH}, with glibc 2.34 or newer (for example Ubuntu 22.04 or later, Debian 12 or later).
- A graphics driver with Vulkan 1.3. Older drivers are refused at start with a message saying why. There is no
  OpenGL mode.
- A desktop session. The viewer uses Wayland natively when it is available, and X11 otherwise.
- The ICU and OpenSSL 3 libraries (on Debian and Ubuntu: libicu and libssl3). Desktop installs normally have both.
- Nothing else needs installing: the .NET runtime the viewer uses is inside this folder.

HOW TO START IT
1. Unpack the archive, keeping the files together:
       tar -xzf {PACKAGE}.tar.gz
2. Start it:
       ./{PACKAGE}/{EXE}
3. Enter the grid's login address, your name and your password on the login screen.
To use X11 instead of Wayland, start it with:
       ./{PACKAGE}/{EXE} --display-driver x11

SETTINGS AND LOGS (the XDG folders; these are the defaults)
- Settings:  ~/.config/{DATA_NAME}
- Cache:     ~/.cache/{DATA_NAME}
- Logs:      ~/.local/state/{DATA_NAME}/logs
The viewer writes nothing into the folder it runs from.

TESTERS WANTED
The Linux builds have not yet been run on a real Linux desktop by the developers. If you try one, please
report what happened, good or bad, on the issues page below.

HOW TO REPORT A PROBLEM
This is an early preview, supported on a best-effort basis. Report problems on the issues page,
https://github.com/JohnLegionH/reverie-viewer/issues
Include:
- what you did and what happened instead,
- the package name ({PACKAGE}),
- your distribution and version, your desktop (Wayland or X11), your graphics card and driver version,
- the newest log file from the logs folder above, and anything the viewer printed in the terminal.
Before you send a log, read it. Logs leave out passwords, but they name the grid and the regions you visited.
