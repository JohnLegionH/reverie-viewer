## Adding to the guide

- One file per section, in this folder, named after the section.
- Plain words and short sentences. Numbered steps for tasks.
- Menu paths are written as **Menu > Item**, and a shortcut in brackets: **Content > Inventory** (Ctrl+I).
- Use a picture only when it helps, and take it from the viewer's existing render pictures.
- When a section is written, change "coming" to "written" above and link it.
