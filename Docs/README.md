# Docs

Documents for people writing add-ons for Reverie Viewer or working on its code.

| File | What |
|---|---|
| ADDONS.md | Add-ons: how to write, package and install one; the manifest, interface 0.1, permissions and jobs |
| ENVIRONMENT-SPEC.md | Water and environment: behaviour spec |
| GLOW-SPEC.md | Glow: behaviour spec |
| PROJECTOR-SPEC.md | Projected lights: behaviour spec |
| SCULPT-SAMPLER-SPEC.md | Sculpt sampler: behaviour spec |
| TERRAIN-COMPOSITION-SPEC.md | Terrain composition: behaviour spec |
| TEXTURE-ORIENTATION-SPEC.md | Texture orientation: behaviour spec |

The behaviour specs describe the official viewer's observable behaviour in our own words; the implementation is written
from them, and no viewer code or comments are copied.
