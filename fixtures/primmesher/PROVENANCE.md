# PrimMesher parity fixtures (the test strategy, section 3.2)

One fixture set, two implementations: the web viewer's TypeScript PrimMesher (`client/src/mesh/primmesher/`) and
this repo's C# port (`core/Viewer.Core/Meshing/PrimMesher.cs`).

## `web-viewer/*.json` — copied verbatim

- Source: web-viewer `master` at `bb91ba5`, files `client/src/mesh/primmesher/__fixtures__/*.json`, last changed by
  `ef337205bd3069d861f61f8ba3f3955b936d9b5d`. Read with `git show` (the web-viewer tree is read-only).
- 17 fixtures. `source: "csharp-3.1.4-with-flag-fix"` (14): generated by the web viewer's throwaway C# harness against
  LibreMetaverse.PrimMesher 3.1.4 with `HasHollow`/`HasProfileCut` forced to the original semantics; that binary never
  emits the bottom cap, so these are compared with the bottom face group removed (as the web viewer's test does).
  `source: "port"` (3: the twisted shapes): frozen from the TS port, because 3.1.4's twist path is unusable as a reference.
- Content: triangle and vertex counts, triangles per prim face, bounding box, 8 sampled triangles (rounded to 1e-5).

## `ts-full/*.full.json.gz` — generated from the TS port

- The COMPLETE output of the TS port (`generatePrimMesh(shape, 'high')`) for each fixture's shape: every viewer face in
  order, as `[primFace, coordIndex1, coordIndex2, coordIndex3, v1 xyz, v2 xyz, v3 xyz, n1 xyz, n2 xyz, n3 xyz, uv1, uv2, uv3]`,
  plus the grouped face list (`groupFaces`). Geometry rounded to 1e-6.
- Generated by a scratch script run with an existing Node 22.16
  (`node --experimental-strip-types`), importing the TS files exported from web-viewer `bb91ba5` with `git show`.
  Nothing was installed and nothing was written into the web-viewer tree.
- Redistribution: generated geometry from BSD-licensed code (see THIRD-PARTY-NOTICES.md); no grid content.
